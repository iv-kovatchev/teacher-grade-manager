# Система за Управление на Оценки

## 📋 Описание

Десктоп приложение за управление на студенти, курсове и оценки, разработено с C# WinForms. Системата позволява на преподавателите да управляват студентска информация, курсове и да въвеждат оценки по българската оценъчна система (2.00 - 6.00).

## ✨ Функционалности

### Управление на Студенти
- ✅ Добавяне на нови студенти
- ✅ Редактиране на съществуващи студенти
- ✅ Изтриване на студенти
- ✅ Валидация на факултетен номер (формат: F123456)

### Управление на Курсове
- ✅ Добавяне на нови курсове
- ✅ Редактиране на съществуващи курсове
- ✅ Изтриване на курсове
- ✅ Избор на ден, час и тип (Лекция/Упражнение)

### Управление на Оценки
- ✅ Въвеждане на оценки за студенти по курсове
- ✅ Редактиране на съществуващи оценки
- ✅ Изтриване на оценки
- ✅ Българска оценъчна система (2.00 - 6.00 със стъпка 0.50)
- ✅ Автоматична проверка за дублиращи се оценки

## 🛠️ Технологии

- **Език:** C# (.NET Framework/Core)
- **UI Framework:** Windows Forms
- **База данни:** SQLite
- **ORM:** Microsoft.Data.Sqlite
- **Архитектура:** Repository Pattern, Service Layer
- **Валидация:** Data Annotations

## 📦 Системни Изисквания

- Windows 10 или по-нова версия
- .NET Framework 4.7.2 или .NET 6.0+
- 50 MB свободно дисково пространство

## 🚀 Как да стартирам приложението

1. Изтеглете проекта
2. Отворете решението (solution) във Visual Studio
3. Натиснете F5 или Run
4. Базата данни (`teachers_management.db`) ще се създаде автоматично при първо стартиране

## 📂 Структура на Проекта
```
TeacherGradeManager/
├── Models/              # Модели (Student, Course, Grade)
├── Repositories/        # Data Access Layer
├── Services/            # Business Logic Layer
├── Forms/               # WinForms UI

```
